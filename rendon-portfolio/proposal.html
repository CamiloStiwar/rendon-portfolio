Portfolio Project Proposal

Camilo Rendon · Software Development AS

Website Purpose

The purpose of this website is to be my professional developer portfolio. It will show the projects I have built in my Software Development program, the skills I am learning, and my resume, so employers can see my work in one place instead of only reading about it on a resume.

Target Audience

  • Hiring managers and recruiters looking for junior web or software developers.
  • Senior developers who review candidates' code during the hiring process.
  • Instructors and classmates who want to see my progress in the program.

Career Goals

  • Finish my Software Development AS degree.
  • Get hired as a junior web developer or junior software developer.
  • Use my management experience to grow into a team lead role in the future.
  • Keep building projects and adding them to this portfolio.

Research: What My Portfolio Needs

Based on my research, these are the components my portfolio needs to help me get a job:

  1. Projects with live demos and source code. Projects are the most important part. Each one should have a working link, a link to the code on GitHub, and a short explanation of what I built and why (Scrimba, n.d.).
  2. A homepage, skills page, projects page, and resume. These are the main pages a web developer portfolio should have (Hostinger, n.d.).
  3. An About page. This tells my story and why I am getting into software development (Arc, n.d.).
  4. Easy to find contact information plus links to GitHub and LinkedIn (Arc, n.d.).
  5. A mobile responsive design. Hiring managers often check portfolios on their phones, so the site has to work on small screens (Scrimba, n.d.).
  6. Fast loading and clean code, since the portfolio itself is an example of my work (Scrimba, n.d.).

Planned Pages

  • Home – short intro and links to my best work
  • About – my background and goals
  • Projects – class and personal projects with demos and code
  • Skills – languages and tools I know (HTML, CSS, JavaScript, etc.)
  • Resume – education and work experience, with a PDF download
  • Contact – email, GitHub, and LinkedIn
